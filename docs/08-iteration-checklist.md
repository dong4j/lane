# Lane 迭代任务清单

问题和基线证据见[全项目审查](07-project-review.md)。主项勾选表示实现已落地并通过对应的本地检查。公开发布和真机交互单独记录。

## 连接与数据

- [x] **01 · 统一 Agent 与手动连接。** 主窗口和菜单逐条显示规则状态。真实回环 OpenSSH 验证 Agent 先开和手动先开两种顺序，每个入口只有一个监听。Agent 先开一条规则时，其他规则保持断开。用户选「保持连接」后，最后一个 Agent 释放时原 PID 和监听继续运行。
- [x] **02 · 收紧外部备份导入。** 「合并」和「恢复」的预览列出忽略的额外 SSH 选项。静态样本验证执行类选项被过滤，保活设置、密钥路径和转发配置保留，原备份逐字节一致。
- [x] **03 · 增加备份恢复与版本保护。** 测试覆盖同 ID 目标端口从 `3111` 回滚到 `3113`、损坏文件恢复和格式 `2` 只读。恢复时留存原始文件，备份中的智能分组一并恢复。
- [x] **04 · 统一代理连接参数。** 测试验证修改 SOCKS5 用户名会触发重连判断并更新 Agent 路径标识，修改备注不会断开。复制命令包含 Lane 代理助手和密码提示参数，终端可交互输入密码。

## Agent 与日常操作

- [x] **05 · 改善 `lane_list` 的入口选择。** 返回 `listen_address`。传入 `include_external: true` 可列举已核实的外部 `-L` 环回入口。真实 OpenSSH 样本验证两个入口可用地址区分，释放引用后仍可访问外部服务。
- [x] **06 · 补齐建连失败审计。** 回环测试覆盖端口占用、SSH 认证失败和外部监听不可用。单元测试覆盖失效规则、按 SSH 主机和目标检索，以及重试同一请求只写一条记录。
- [x] **07 · 降低审计写入的主线程开销。** SQLite 按租约更新，定时检查只遍历活跃记录。测试覆盖旧 JSON 迁移、故障写入回退和重启恢复。下表记录相同样本的耗时。
- [x] **08 · 导入拆分 SSH 配置和多个别名。** 测试覆盖 `Include` 通配、带空格的路径、循环、未匹配文件、`Match` 跳过和两个显式别名，导入预览显示来源。
- [x] **09 · 改善远程转发标注。** 菜单使用规则自定义名称并标注「服务器入口」。路径图说明目标从此 Mac 访问。已通过构建和三类转发的 OpenSSH 回环测试，菜单交互见真机清单。
- [x] **10 · 准确定位端口故障。** 验证器返回具体字段，地址错误会打开高级选项并请求焦点。测试覆盖同号端口、不同绑定地址和 IPv4／IPv6 的占用者匹配。实际焦点切换见真机清单。
- [x] **11 · 区分通用 MCP 客户端。** 两个真实 SDK 客户端使用同一份通用配置，记录分别显示各自的自报名称，鉴权仍由本机配对凭据决定。

## 发布与验收

- [x] **12 · 准备稳定安装入口。** 本机生成 `Lane-0.1.0-macOS-arm64.zip` 和 `SHA256SUMS.txt`。工作流配置为由匹配的标签触发签名、公证和 Release，英文和中文 README 都提供下载与校验步骤。
  - [ ] **公开发布。** GitHub 当前没有 Lane Release。需要为 `release` 环境配置签名和公证凭据，确认发布版本，再用公开下载包完成首次启动验收。
- [x] **13 · 固化高频回归的发布验收。** 本机使用与 CI 一致的 `mcp==1.26.0`，从实际通用 JSON 走完列举、建连、取址、访问和释放。CI 工作流已纳入这条路径。
  - [ ] **真机交互。** [发布验收](09-release-verification.md)记录菜单边界、整行折叠、独立复制、键盘焦点、浅深色、VoiceOver 和睡眠唤醒。在最低支持版本和当前使用的 macOS 上走查。

本机通过 66 项回归和单独运行的性能测试。Debug 与 Release 均可构建，Release 压缩包通过解包签名和 SHA-256 校验，包内最低系统为 macOS 14。错误版本标签被打包脚本拒绝。GitHub 工作流通过 `actionlint`。

## 审计性能

同一台 Mac 使用同一份回环规则和预置历史。每组预热一次，对后续三次 `lane_request` 取中位数。测量涵盖主线程本地处理、审计写入和演示运行时，SSH 网络耗时在测量范围外。
