# Lane 使用指南

[English](usage.md) · [主页](../README.zh-CN.md) · [Agent MCP](06-agent-mcp.md)

## 新建第一条本地转发

在主窗口点「新建隧道」，填写 SSH 别名或主机名。使用别名时，可以沿用 OpenSSH 配置里的凭据、跳板机和连接选项。

| 规则 | 客户端从哪连接 | 从哪访问目标 |
| --- | --- | --- |
| 本地 `-L` | 本机端口，例如 `127.0.0.1:15432` | 从 SSH 主机访问固定服务，例如 `db.internal:5432` |
| 远程 `-R` | SSH 服务器的端口，例如服务器上的 `127.0.0.1:18080` | 从这台 Mac 访问固定服务，例如 `127.0.0.1:3000` |
| 动态 `-D` | 本机 SOCKS5 代理，例如 `127.0.0.1:1080` | 从 SSH 主机访问客户端为每次连接指定的目标 |

可以「保存并连接」，也可以保存后从菜单栏连接。Agent 已打开其中一条规则时，点「保持连接」会复用这个监听，并启动其他启用的规则。路径图会标出发起连接的一端和经过 SSH 加密的区段。只供本机客户端访问时，建议监听环回地址，例如 `127.0.0.1`。远程监听的可见范围取决于 SSH 服务器的策略。

「已连接」表示 SSH 和转发规则已就绪。目标服务是否可用，可以在实际客户端发一次数据库查询、HTTP 请求或 SOCKS5 连接来验证。

## 从菜单栏取地址

菜单栏可连接或断开已保存的隧道、复制地址，也可以重新打开主窗口。已连接隧道或本机发现的会话有多个入口时，点击行内名称、空白处或最右侧箭头即可展开或收起。在多入口的外部会话上右键可打开主窗口详情。连接失败时，点「查看」可回到主窗口定位问题。

「本机发现」列出当前 macOS 用户的 SSH 进程及可观察到的转发。多个入口按进程归组，能读取参数时会尝试匹配监听与转发规则。只有远端转发声明时，会显示请求的地址并标为「远端未核实」。要修改或停止外部会话，请回到启动它的工具或终端。

## 导入、导出和偏好设置

「设置 → 数据」可以预览从 `~/.ssh/config` 读取的显式转发规则，也可以导入兼容备份。勾选要添加的条目后再导入。导出只写配置，凭据留在钥匙串。

「通用」可以调整外观、语言、菜单栏与程序坞、登录启动和通知。语言在下次打开应用时切换。「连接」里可配置唤醒后的处理方式及自定义 OpenSSH 路径。单条隧道是否随应用连接，在它的编辑器里设置。

## 排查连接问题

1. 展开「诊断与日志」，查看 SSH 命令、认证阶段和最近事件。内置代理的复制命令会使用 Lane 程序，需要代理密码时可在终端输入。
2. 如果监听端口已被占用，找到对应规则，换一个端口或释放原端口，再重试。
3. 第一次遇到 SSH 主机指纹时，从可信渠道核对后再接受。已有指纹变化时，先联系服务器管理员核实。
4. Lane 显示「已连接」而客户端报错时，从路径图标出的机器验证目标服务是否可达。

## 本地数据

隧道配置保存在 `~/Library/Application Support/Lane/tunnels.json`。移动 `Lane.app` 后，请重新复制 MCP 接入配置，让客户端使用新的应用路径。

想用示例配置体验时，先退出正在运行的应用，再带 `--demo` 启动。

```sh
open .build/Lane.app --args --demo
```

演示隧道和偏好保存在内存里。正常使用时，关闭主窗口后隧道仍在运行。退出 Lane 会结束受管连接和 Agent 申请。外部会话由原进程继续管理。
