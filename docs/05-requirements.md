# Portlane 首版需求

Portlane 是一款 macOS 菜单栏工具，用来连接 SSH 隧道、复制客户端入口和查看本机已有的转发。已确认的 [UI v2](04-ui-v2.md) 是窗口、菜单栏、编辑器和动效的验收基准。

## 日常使用

1. 点开菜单栏，找到受管隧道并连接。单规则连接就绪后可直接复制，多规则可展开并分别复制。操作后面板保持打开，同一位置显示“已复制”。
2. 打开主窗口配置连接、切换规则、查看路径和解决故障。搜索同时覆盖受管和本机发现的名称、主机、端口及已知目标。关闭主窗口后仍能从菜单栏操作。
3. 打开菜单栏或主窗口即可看到本机发现的 SSH 会话。外部会话可以查看、搜索和复制，连接与断开由启动它的工具负责。

| 类型 | 谁发起连接 | 复制内容 | 规则用途说明 |
| --- | --- | --- | --- |
| 本地 `-L` | Mac 客户端 | `127.0.0.1:15432` | 在 Mac 打开本机端口，访问 SSH 主机能访问的固定服务。 |
| 远程 `-R` | SSH 服务器上的客户端 | `127.0.0.1:18080`，按钮标明服务器 | 在服务器使用其监听端口，访问 Mac 上的固定服务。实际可见范围受服务器策略影响。 |
| 动态 `-D` | Mac 上支持 SOCKS5 的客户端 | `socks5://127.0.0.1:1080` | 客户端通过代理选择访问目标，表单只要求代理监听端口。 |

## 配置与上手

- 支持 SSH 别名和 `user@host`、一条连接内的多条规则，以及每条规则独立的名称和备注。高级选项提供监听地址、SSH 端口、私钥路径和按隧道自动重连。默认使用本机 SSH 配置与环回监听。
- 新建入口提供“仅保存”和“保存并连接”。保存前校验必填值和端口，定位第一个错误字段。修改已连接隧道的主机、认证或规则时，明确提示会短暂断开。只改名称或备注时保持现有会话。
- 主窗口、编辑器和首次使用入口共用路径组件。`-L` 光点从 Mac 发往固定目标，`-R` 从服务器回到 Mac，`-D` 轮流发往两个示例目标。箭头和说明表达连接发起方向。编辑和首次使用时标明“路径预览”或“路径示例”；用户开启减少动态效果后仍能从静态箭头和文字理解路径。
- 从 `~/.ssh/config` 预览并导入具体 `Host` 块中声明的 TCP 转发，可逐条选择连接配置。没有转发的 SSH 别名可直接在编辑器使用。首次启动根据真实配置和发现结果选择进入列表或引导。

## 外部 SSH 会话

- 同一进程的多个监听入口归在同一会话。例如连接至 `m4` 的进程如果监听 `3111` 和 `3113`，两条规则出现在同一条 `m4` 会话下。
- 匹配到 `-L` 或 `-D` 启动参数与本机监听时，显示方向和已知目标。只看到 OpenSSH 监听时，保留可复制地址，方向或目标显示未知。纯 `-R` 声明显示“远端未核实”。
- 刷新成功后移除已经停止的会话。刷新失败时保留上次结果并给出反馈。筛选范围是当前账号可观察到的 OpenSSH 进程。内嵌 SSH 客户端、其他用户与虚拟机内的会话可能不可见。

## 认证、故障和验收

- 系统密钥和 `ssh-agent` 可直接使用。首次连接显示主机和完整指纹，用户决定是否信任。指纹变化停止连接。对密码、私钥口令和交互式验证码提供原生验证提示，可取消。可选择将支持的凭据记入钥匙串。
- 显示已断开、连接中、等待验证、已连接、断开中、等待重连和失败。只有转发监听成功或收到服务器确认时才标为就绪。远端服务是否可用由实际客户端访问决定。
- 端口冲突定位到具体规则，可查看已知占用进程、编辑监听端口和重新连接。诊断可展开最近事件、复制 SSH 命令和当前日志。掉线时按配置重试，主动断开则取消重试。正常退出只结束 Portlane 持有的 SSH 子进程。
- macOS 默认浅色和深色均对照 v2，窗口与表单可应对较窄屏幕。键盘可新建、搜索、选隧道、进入规则及复制动作。辅助功能标签读出入口所属和连接方向。

首版范围为 TCP 本地、远程和动态转发。批量操作、第三方客户端迁移、正式发布与系统安装包安排在后续阶段。
